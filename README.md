# SplitLine — JPG / PNG 画像 縦n分割スタジオ

JPG（`.jpg` / `.jpeg`）および PNG（`.png`）画像を縦方向（上下）または左右方向に指定した $n$ 分割・カスタム位置でスライスし、分割前の配置プレビューやピース間隔（Gap / ホワイトスペース）を入れたグリッドレイアウト・シミュレーションを行える Web ツールです。

すべての画像処理はブラウザ内の **HTML5 Canvas API** と **JSZip** で完結し、**外部サーバーへの画像送信は一切行われません**（100% クライアントサイド処理）。

---

## 主な機能

1. **自由な分割数 ($n$) 設定**
   - **数値入力フィールド**（`2`〜`50`分割、`-` / `+` ステッパー付き）、**スライダー**、および**プリセットボタン**（2・3・4・5・6・8・10・12分割）で任意の分割数を指定可能。
   - **上下に $n$ 分割（縦並び・長尺画像向け）**と**左右に $n$ 分割（短冊カラム）**の切り替えに対応。
   - **均等 $n$ 分割**、**個別位置調整（1px単位）**、**指定ピクセル間隔（px）ごとの分割**、および境界の文字切れを防ぐ**のりしろ（オーバーラップ px）設定**を搭載。

2. **分割前のリアルタイム・プレビューとカット線ドラッグ調整**
   - **カット線オーバーレイ表示**: 元画像上に各ピースの番号・ピクセル寸法とカット線を表示し、カット線をドラッグして 1px 単位で直感的に位置調整可能。
   - **分割後イメージ（セパレート配置）表示**: 分割実行前に、切り出される各ピースの並び状態を実寸比率で事前確認可能。

3. **ピース間隔（Gap）設定とグリッドレイアウト・シミュレーション**
   - 分割結果の各ピース間に一定のピクセル間隔（`0`〜`200 px` のホワイトスペース）を挿入し、SNS投稿やWebレイアウトに並べた際のグリッド表示をシミュレーション。
   - 余白カラーは `ホワイト (#FFFFFF)`、`ライトグレー (#F1F5F9)`、`ダーク (#0F172A)`、`透過 (PNG)` から選択可能。
   - 余白を含めたグリッド全体の仕上がり寸法（例: `1200 × 1920 px`）をリアルタイム算出。

4. **多様な書き出し・保存オプション**
   - 各ピースの**個別ダウンロード**および拡大ライトボックス確認。
   - 全ピースをまとめた **一括 ZIP ダウンロード**（連番ファイル名自動付与）。
   - ピース間隔（ホワイトスペース）を反映した **余白付きグリッド結合画像（PNG）** の書き出し。

## ローカル開発・ビルド手順

### 必要環境
- Node.js 22 以上
- npm

### セットアップと起動

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (http://localhost:3000)
npm run dev

# 単体テストの実行
npm test

# 本番用ビルド (dist/ ディレクトリに出力)
npm run build

# ビルド結果のローカルプレビュー
npm run preview
```

## GitHub Pages へのデプロイ手順

本プロジェクトは以下の設定により、そのまま **GitHub Pages** にデプロイできる構成になっています。

- `vite.config.ts` に `base: './'`（相対パス出力）を設定済みのため、`https://<ユーザー名>.github.io/<リポジトリ名>/` のようなサブパス環境でもカスタムドメイン環境でもそのまま動作します。
- `.github/workflows/deploy.yml` に GitHub Actions 自動デプロイワークフローを同梱しています。

### 方法1: GitHub Actions による自動デプロイ（推奨）

1. このプロジェクトを GitHub リポジトリの `main` ブランチへ push します。
2. GitHub リポジトリの **Settings** > **Pages** を開きます。
3. **Build and deployment** の **Source** で **GitHub Actions** を選択します。
4. `main` ブランチへの push 時に `.github/workflows/deploy.yml` が自動実行され、単体テスト・Vite ビルド（`dist/`）を経て GitHub Pages へ公開されます。
   - 手動で再デプロイしたい場合は、GitHub の **Actions** タブ > **Deploy to GitHub Pages** > **Run workflow** からいつでも実行できます。

### 方法2: `dist` フォルダの手動デプロイ（`gh-pages` ブランチ等を使う場合）

ローカルでビルドした静的ファイルをそのままホスティングする場合:

```bash
npm run build
```

生成された `dist/` ディレクトリ内のファイル一式を `gh-pages` ブランチや任意の静的ホスティングサービスへアップロードしてください。
